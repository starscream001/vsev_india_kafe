Что это такое?

AI Defect Reviewer & Interviewer — MVP-решение для автоматизации проверки качества дефектов.

Инструмент помогает QA-командам:
  • уменьшать количество возвратов дефектов;
  • ускорять анализ проблем разработчиками;
  • повышать качество баг-репортов;
  • формировать единый стандарт оформления дефектов;
  • снижать количество ручной коммуникации между QA и DEV.

Основные возможности

AI Interviewer

Задаёт уточняющие вопросы тестировщику и помогает собрать недостающую информацию.

AI Defect Builder

Автоматически формирует структурированный баг-репорт.

AI Reviewer

Проверяет дефект глазами разработчика и QA Lead.

Quality Score

Оценивает качество дефекта по шкале от 0 до 100.

Установка

1. Скачать проект

git clone https://stash.delta.sbrf.ru/users/22189365/repos/ai-defect-interviewer/browse

2. Перейти в папку проекта

cd ai-defect-interviewer

3. Запустить проект

bash run.sh

4. Открыть браузер

http://127.0.0.1:8000/index.html
