AI Defect Reviewer & Interviewer

Локальный AI-помощник для QA-команд, который помогает собирать качественные дефекты, выполнять AI-ревью и повышать качество баг-репортов перед передачей в разработку.

Python 3 GigaCode CLI Закрытый контур AI Review Quality Score

Что это такое?

AI Defect Reviewer & Interviewer — это MVP-инструмент для автоматизации проверки качества дефектов.

Он помогает тестировщику:

  • собрать полное описание дефекта;
  • не забыть важные детали;
  • получить AI-рекомендации;
  • сформировать Jira-ready баг;
  • уменьшить количество возвратов дефектов от разработчиков.

Что умеет продукт?

Функция Описание
AI Interviewer Задаёт уточняющие вопросы тестировщику
AI Defect Builder Формирует готовый баг-репорт
AI Reviewer Проверяет качество дефекта глазами разработчика
Quality Score Оценивает качество дефекта от 0 до 100
Developer Recommendations Подсказывает, чего не хватает для анализа

Что проверяет AI?

Проверка Что анализируется
Шаги воспроизведения Можно ли воспроизвести дефект
Expected Result Понятно ли правильное поведение
Actual Result Понятно ли, что именно сломалось
Окружение Стенд, браузер, версия приложения
Артефакты Логи, скриншоты, requestId, traceId

Как установить?

1. Скачать проект

git clone https://github.com/starscream001/vsev_india_kafe.git

2. Перейти в папку

cd vsev_india_kafe

3. Запустить проект

bash run.sh

4. Открыть браузер

http://127.0.0.1:8000/index.html
